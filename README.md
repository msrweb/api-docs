# Microsoft Research API documentation

Visual documentation for the Microsoft Research REST API, generated from its
OpenAPI 3.0 schema.

- [View the API reference](https://msrweb.github.io/api-docs/)
- [View the source schema](https://www.microsoft.com/en-us/research/wp-json/microsoft-research/v2/schema)
- [Explore the WordPress REST namespace](https://www.microsoft.com/en-us/research/wp-json/microsoft-research/v2/)

GitHub Pages refreshes the published schema daily and whenever `main` changes.
The committed `openapi.json` is a snapshot for local viewing and review.
